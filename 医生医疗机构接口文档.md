# 医生医疗机构接口文档

莲藕系统（imax）医生医疗机构相关接口说明。

## 公共参数

### 请求头（Headers）

| 参数名 | 类型   | 是否必填 | 说明   |
|--------|--------|----------|--------|
| sign   | string | 是       | 固定值 `lo` |

### URL 查询参数

所有接口 URL 均需携带以下查询参数：

| 参数名    | 类型   | 是否必填 | 说明     |
|-----------|--------|----------|----------|
| nonce     | string | 是       | 随机数   |
| timestamp | string | 是       | 时间戳   |
| sign      | string | 是       | 签名     |

示例查询串：

```
nonce=1486837976&timestamp=1597991281&sign=09149C743CDEEB7FB8E688701AD0349F013AF2FB
```

### 环境地址

| 环境     | Base URL                              |
|----------|---------------------------------------|
| 测试环境 | `http://testimax.lianouyiyuan.com`    |
| 生产环境 | `http://imax.lianouyiyuan.com`        |

### 通用响应结构

| 参数名 | 类型   | 说明                    |
|--------|--------|-------------------------|
| code   | int    | `1` = 成功，其他 = 失败 |
| msg    | string | 消息                    |
| data   | mixed  | 业务数据                |

## 一、查询医生医疗机构信息

分页查询医生医疗机构信息及缺失字段列表。

### 请求

- **方法**：`POST`
- **Content-Type**：`application/json`

**测试环境**

```
POST http://testimax.lianouyiyuan.com/api/doctorExt/GetDoctorMedicalPage?nonce=1486837976&timestamp=1597991281&sign=09149C743CDEEB7FB8E688701AD0349F013AF2FB
```

**生产环境**

```
POST http://imax.lianouyiyuan.com/api/doctorExt/GetDoctorMedicalPage?nonce=1486837976&timestamp=1597991281&sign=09149C743CDEEB7FB8E688701AD0349F013AF2FB
```

### 请求 Body

```json
{
    "pageSize": 10,
    "pageIndex": 1,
    "qualificationCertCode": "",
    "practicingCertCode": ""
}
```

| 字段名                | 类型   | 是否必填 | 说明               |
|-----------------------|--------|----------|--------------------|
| pageSize              | int    | 是       | 每页数量（如 `10`）|
| pageIndex             | int    | 是       | 页码（从 `1` 开始）|
| qualificationCertCode | string | 否       | 资格证书编号       |
| practicingCertCode    | string | 否       | 执业证书编号       |

### 响应参数说明

#### data 对象

| 字段名 | 类型  | 说明     |
|--------|-------|----------|
| total  | int   | 总数量   |
| list   | array | 医生列表 |
| extObj | mixed | 扩展对象 |

#### list 数组元素（医生维度）

| 字段名                | 类型   | 说明                                              |
|-----------------------|--------|---------------------------------------------------|
| doctorFileId          | string | 医生档案 ID                                       |
| idCard                | string | 身份证号码                                        |
| qualificationCertCode | string | 资格证书编号                                      |
| practicingCertCode    | string | 执业证书编号                                      |
| doctorName            | string | 医生名称                                          |
| isDocMedical          | bool   | 是否有医疗机构信息（`false` = 没有，`true` = 有） |
| docMedicalList        | array  | 医疗机构列表                                      |

#### docMedicalList 数组元素

| 字段名      | 类型   | 说明           |
|-------------|--------|----------------|
| aId         | long   | 医生医疗机构主键 |

| updateField | array  | 为空的字段名列表 |

| 字段名                 | 说明                                                                 |
|------------------------|----------------------------------------------------------------------|
| medicalInstitutionType | 医疗机构类型：`1` = 第一执业，`2` = 多点执业                         |

| healthCommissionBase   | 卫健委图片                                                           |
| institutionBase        | 机构端图片                                                           |

## 二、更新医生医疗机构信息

新增或更新指定医生的医疗机构相关信息。

### 请求

- **方法**：`POST`
- **Content-Type**：`application/json`

**测试环境**

```
POST http://testimax.lianouyiyuan.com/api/doctorExt/UpdateDoctorMedical?nonce=1486837976&timestamp=1597991281&sign=09149C743CDEEB7FB8E688701AD0349F013AF2FB
```

**生产环境**

```
POST http://imax.lianouyiyuan.com/api/doctorExt/UpdateDoctorMedical?nonce=1486837976&timestamp=1597991281&sign=09149C743CDEEB7FB8E688701AD0349F013AF2FB
```

### 请求 Body

```json
{
    "operationType": 0,
    "aId": 7,
    "doctorFileId": "4636767112646389817",
    "doctorName": "饿了么测试-孙鑫磊4",
    "iDCard": "",
    "qualificationCertCode": "",
    "practicingCertCode": "",
    "medicalInstitutionType": 0,
    "practiceProvince": "",
    "practiceCity": "",
    "hospital": "",
    "hospitalLevel": 0,
    "departmentName": "",
    "recordDate": "2026-09-26",
    "recordExpireDate": "",
    "healthCommissionBase": "",
    "institutionBase": ""
}
```

| 字段名                 | 类型     | 是否必填 | 说明                                                                 |
|------------------------|----------|----------|----------------------------------------------------------------------|
| operationType          | int      | 是       | 操作类型：`0` = 新增，`1` = 更新                                     |
| aId                    | long     | 条件必填 | 医生医疗机构主键（`operationType = 1` 时必填）                       |
| doctorFileId           | string   | 是       | 医生档案编号                                                         |
| iDCard                 | string   | 是       | 身份证号码                                                           |
| qualificationCertCode  | string   | 是       | 资格证书编号                                                         |
| practicingCertCode     | string   | 是       | 执业证书编号                                                         |
| doctorName             | string   | 是       | 医生姓名                                                             |
| medicalInstitutionType | int      | 否       | 医疗机构类型：`1` = 第一执业，`2` = 多点执业                         |
| practiceProvince       | string   | 否       | 省份                                                                 |
| practiceCity           | string   | 否       | 城市                                                                 |
| hospital               | string   | 否       | 医院                                                                 |
| hospitalLevel          | int      | 否       | 医院等级（枚举同查询接口）                                           |
| departmentName         | string   | 否       | 科室                                                                 |
| recordDate             | DateTime | 否       | 备案日期                                                             |
| recordExpireDate       | DateTime | 否       | 备案到期日期                                                         |
| healthCommissionBase   | string   | 否       | 卫健委图片 base64                                                    |
| institutionBase        | string   | 否       | 机构端图片 base64                                                    |

### 响应示例

```json
{
    "code": 1,
    "msg": "操作成功",
    "data": "更新成功"
}
```

### 响应参数说明

| 参数名 | 类型   | 说明                    |
|--------|--------|-------------------------|
| code   | int    | `1` = 成功，其他 = 失败 |
| msg    | string | 消息                    |
| data   | string | 更新结果描述            |

## 与本项目管线的关系

核对产物 `workspace/to_submit.json` 经 [`postable_body`](../src/reconcile/to_supplement.py) 展平后即为上述 **UpdateDoctorMedical** 请求体：

| 中间 JSON | 提交 JSON |
|-----------|-----------|
| 顶层 `operationType`、`aId`、`doctorFileId`、`doctorName`、`iDCard`、`qualificationCertCode`、`practicingCertCode` | 原样出现在请求体顶层 |
| `updateField` 对象内的业务字段 | 展平到请求体顶层（与示例 JSON 同级） |
| `_capture`、`_op` | **不提交** |

更新（`operationType=1`）时，`updateField` 内空字符串字段不会写入请求体；新增（`operationType=0`）保留空占位。

完整管线步骤与字段映射见 [`CONTEXT.md`](CONTEXT.md)。
