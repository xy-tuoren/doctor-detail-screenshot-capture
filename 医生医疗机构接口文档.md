# 医生医疗机构接口文档

莲藕系统（imax）医生医疗机构相关接口说明。

## 公共参数

### 请求头（Headers）

| 参数名 | 类型   | 是否必填 | 说明   |
|--------|--------|----------|--------|
| sign   | string | 是       | 固定值 `lo` |

### URL 查询参数

所有接口 URL 均需携带以下查询参数：

| 参数名    | 类型   | 是否必填 | 说明     |
|-----------|--------|----------|----------|
| nonce     | string | 是       | 随机数   |
| timestamp | string | 是       | 时间戳   |
| sign      | string | 是       | 签名     |

示例查询串：

```
nonce=1486837976&timestamp=1597991281&sign=09149C743CDEEB7FB8E688701AD0349F013AF2FB
```

### 环境地址

| 环境     | Base URL                              |
|----------|---------------------------------------|
| 测试环境 | `http://testimax.lianouyiyuan.com`    |
| 生产环境 | `http://imax.lianouyiyuan.com`        |

### 通用响应结构

| 参数名 | 类型   | 说明                    |
|--------|--------|-------------------------|
| code   | int    | `1` = 成功，其他 = 失败 |
| msg    | string | 消息                    |
| data   | mixed  | 业务数据                |

## 一、查询医生医疗机构信息

分页查询医生医疗机构信息及缺失字段列表。

### 请求

- **方法**：`POST`
- **Content-Type**：`application/json`

**测试环境**

```
POST http://testimax.lianouyiyuan.com/api/doctorExt/GetDoctorMedicalPage?nonce=1486837976&timestamp=1597991281&sign=09149C743CDEEB7FB8E688701AD0349F013AF2FB
```

**生产环境**

```
POST http://imax.lianouyiyuan.com/api/doctorExt/GetDoctorMedicalPage?nonce=1486837976&timestamp=1597991281&sign=09149C743CDEEB7FB8E688701AD0349F013AF2FB
```

### 请求 Body

```json
{
    "pageSize": 10,
    "pageIndex": 2
}
```

| 字段名    | 类型 | 是否必填 | 说明               |
|-----------|------|----------|--------------------|
| pageSize  | int  | 是       | 每页数量（如 `10`）|
| pageIndex | int  | 是       | 页码（从 `1` 开始）|

### 响应示例

```json
{
    "code": 1,
    "msg": "操作成功",
    "data": {
        "total": 6865,
        "list": [
            {
                "aId": 58,
                "doctorFileId": "5535625461229322308",
                "doctorName": "钟小荣",
                "hospital": "揭阳市榕城区人民医院",
                "updateField": [
                    "recordDate",
                    "recordExpireDate",
                    "healthCommissionExpireDate",
                    "institutionExpireDate",
                    "institutionUrl"
                ]
            },
            {
                "aId": 69,
                "doctorFileId": "4963756955185644359",
                "doctorName": "刘明",
                "hospital": "揭阳市榕城区人民医院",
                "updateField": [
                    "recordDate",
                    "recordExpireDate",
                    "healthCommissionExpireDate",
                    "institutionExpireDate",
                    "institutionUrl"
                ]
            }
        ],
        "extObj": null
    }
}
```

### 响应参数说明

#### data 对象

| 字段名 | 类型  | 说明     |
|--------|-------|----------|
| total  | int   | 总数量   |
| list   | array | 医生列表 |
| extObj | mixed | 扩展对象 |

#### list 数组元素

| 字段名                     | 类型   | 说明                                                                 |
|----------------------------|--------|----------------------------------------------------------------------|
| aId                        | long   | 表主键 ID                                                            |
| doctorFileId               | string | 医生档案 ID                                                          |
| doctorName                 | string | 医生名称                                                             |
| hospital                   | string | 医院名称                                                             |
| updateField                | array  | 缺失/待补全的字段名列表                                              |
| medicalInstitutionType     | int    | 医疗机构类型：`1` = 第一执业，`2` = 多点执业                         |
| practiceProvince           | string | 省份                                                                 |
| practiceCity               | string | 城市                                                                 |
| hospitalLevel              | int    | 医院等级（见下方枚举）                                               |
| departmentName             | string | 科室名称                                                             |
| recordDate                 | string | 备案日期                                                             |
| recordExpireDate           | string | 备案到期日期                                                         |
| healthCommissionExpireDate | string | 卫健委到期日期                                                       |
| healthCommissionUrl        | string | 卫健委图片                                                           |
| institutionExpireDate      | string | 机构端到期日期                                                       |
| institutionUrl             | string | 机构端图片                                                           |

#### 医院等级（hospitalLevel）枚举

| 值 | 说明   |
|----|--------|
| 1  | 一级   |
| 2  | 一级甲 |
| 10 | 二级   |
| 11 | 二级甲 |
| 12 | 二级乙 |
| 13 | 二级丙 |
| 20 | 三级   |
| 21 | 三级甲 |
| 22 | 三级乙 |
| 23 | 三级丙 |
| 91 | 未定级 |
| 92 | 未查到 |

## 二、更新医生医疗机构信息

更新指定医生的医疗机构相关信息。

### 请求

- **方法**：`POST`
- **Content-Type**：`application/json`

**测试环境**

```
POST http://testimax.lianouyiyuan.com/api/doctorExt/UpdateDoctorMedical?nonce=1486837976&timestamp=1597991281&sign=09149C743CDEEB7FB8E688701AD0349F013AF2FB
```

**生产环境**

```
POST http://imax.lianouyiyuan.com/api/doctorExt/UpdateDoctorMedical?nonce=1486837976&timestamp=1597991281&sign=09149C743CDEEB7FB8E688701AD0349F013AF2FB
```

### 请求 Body

```json
{
    "AId": 7,
    "DoctorFileId": "4636767112646389817",
    "doctorName": "饿了么测试-孙鑫磊4",
    "MedicalInstitutionType": 0,
    "PracticeProvince": "",
    "PracticeCity": "",
    "Hospital": "",
    "HospitalLevel": 0,
    "DepartmentName": "",
    "RecordDate": "2026-09-26",
    "RecordExpireDate": "",
    "HealthCommissionExpireDate": "",
    "HealthCommissionUrl": "",
    "InstitutionExpireDate": "",
    "InstitutionUrl": "1123123123"
}
```

> 注意：请求示例中部分字段使用 PascalCase（如 `AId`、`DoctorFileId`），参数说明表中使用 camelCase。调用时请与接口实际约定保持一致。

| 字段名                     | 类型     | 是否必填 | 说明                                                                 |
|----------------------------|----------|----------|----------------------------------------------------------------------|
| AId / aId                  | long     | 是       | 表主键 ID                                                            |
| doctorFileId               | string   | 是       | 医生档案编号                                                         |
| doctorName                 | string   | 是       | 医生姓名                                                             |
| medicalInstitutionType     | int      | 否       | 医疗机构类型：`1` = 第一执业，`2` = 多点执业                       |
| practiceProvince           | string   | 否       | 省份                                                                 |
| practiceCity               | string   | 否       | 城市                                                                 |
| hospital                   | string   | 否       | 医院                                                                 |
| hospitalLevel              | int      | 否       | 医院等级（枚举同查询接口）                                           |
| departmentName             | string   | 否       | 科室                                                                 |
| recordDate                 | DateTime | 否       | 备案日期                                                             |
| recordExpireDate           | DateTime | 否       | 备案到期日期                                                         |
| healthCommissionExpireDate | DateTime | 否       | 卫健委到期日期                                                       |
| healthCommissionUrl        | string   | 否       | 卫健委图片                                                           |
| institutionExpireDate      | DateTime | 否       | 机构端到期日期                                                       |
| institutionUrl             | string   | 否       | 机构端图片                                                           |

### 响应示例

```json
{
    "code": 1,
    "msg": "操作成功",
    "data": "更新成功"
}
```

### 响应参数说明

| 参数名 | 类型   | 说明                    |
|--------|--------|-------------------------|
| code   | int    | `1` = 成功，其他 = 失败 |
| msg    | string | 消息                    |
| data   | string | 更新结果描述            |
