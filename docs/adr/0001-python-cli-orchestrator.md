# 统一 Python CLI 编排器取代 cmd 入口

原本各功能由 `cmd/` 下的 `.cmd` 入口手工串联，缺少端到端流程。决定以单一 Python CLI 作为唯一入口：提供一个一键跑完的编排命令，外加每一步（查询、解析导出、核对生成缺失名单、补全写回、机构端采集、卫健委采集）都可单独运行的子命令，步骤之间通过中间产物（xlsx/json）传递而非内存耦合。整条管线由莲藕查询结果的 `updateField`（缺失字段）驱动——缺什么字段就补什么、缺哪类图就采集谁，各步骤的工作名单自动生成，不再手工维护 `config.json` 的 names 列表。选择"编排器+可单跑步骤"而非单一巨命令，是为了便于排错、断点续跑和人工介入。
