# 机构端导出列到莲藕日期字段的映射规则

一个医生只会出现在主执业导出或多执业导出之一（互斥），在哪张表被匹配到就决定其执业类型与日期来源。映射规则：

- 在**主执业导出**命中：`recordDate`（备案日期）← `审核日期`；其余到期日期不补（主执业导出无结束日期）。
- 在**多执业导出**命中：`recordDate`（备案日期）← `开始日期`；`recordExpireDate`（备案到期日期）← `结束日期`。
- 图片字段：`healthCommissionBase`、`institutionBase` 由截图脚本填入 base64，不从导出表映射。
- 身份证号码仅用于莲藕名单与机构端导出的**本地对账匹配**，不写入 `UpdateDoctorMedical`。

只写回 `updateField` 点名缺失、且导出该行确有值的字段；导出无值则跳过。其中"主执业用审核日期充当备案日期""三个不同含义的到期日期同取结束日期"属于业务约定、在代码里看不出缘由，故在此显式记录，避免后人误改。
